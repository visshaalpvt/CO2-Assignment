BRUTE_FORCE_CLOSEST(P)
 bestDistance = infinity; bestPair = none; pairCount = 0
 for i = 0 to n-2:
   for j = i+1 to n-1:
     pairCount += 1
     d = EuclideanDistance(P[i],P[j])
     if d < bestDistance: update bestDistance and bestPair
 return bestPair, bestDistance, pairCount
Unique pairs = n(n-1)/2; time Θ(n²), auxiliary space Θ(1).
